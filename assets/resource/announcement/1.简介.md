# 绿梦：时空之声 MAA 简介

《绿梦：时空之声》是一款 3D 科幻横版 ACT + 卡牌养成二次元游戏（开发商：竹子游戏）。

本项目是基于图像识别技术的自动化工具（MAA），运行于 MuMu 模拟器平台，用于自动化完成游戏内的重复性操作。

## 已实现功能

- **战斗流程**：主菜单 → 蚀务日常 → 副本 → 构战回廊 → 受蚀者·异变体-I → 开始挑战 → 出战 → 战斗三键连点直至结算
- **蚀务之礼签到**：活动限时签到领取
- **值勤作战补给**：每日登录自动签到（累计登录奖励）
- **奇遇臻选赏奖券**：今日获取奖券任务领取

## 技术栈

- 框架：[MaaFramework](https://github.com/MaaXYZ/MaaFramework)（LGPL-3.0）
- 界面：[MFAAvalonia](https://github.com/MaaXYZ/MaaFramework)（官方 Avalonia 桌面 UI）
- 识别引擎：OCR（PaddleOCR）+ 图像模板匹配
- 制作工具：DeepSeek Harness（DSH）智能体全程制作

## 快速开始

1. 下载最新 release 解压
2. 启动 MuMu 12 模拟器，分辨率设为 16:9 横屏（1600×900）
3. 确保游戏《绿梦：时空之声》已安装并能正常进入
4. 运行 MFAAvalonia.exe，连接模拟器，勾选任务启动
